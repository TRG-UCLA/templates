# TRG shared assets

Templates and identity assets of the [Taciroglu Research Group](https://tacirogluresearch.org)
at UCLA. Click a file, then use the **Download raw file** button (or clone the repo).

## Presentation templates

| File | Use it for |
|---|---|
| `TRG-template-site-livery.pptx` | Research talks and seminars. Hazard palette (amber / teal / coral) matching tacirogluresearch.org. Five layouts: title, section divider, content, three-hazard panels, closing. |
| `TRG-template-ucla-livery.pptx` | Campus, proposal, and university contexts. UCLA-color TRG logo livery, same five layouts. |

Duplicate the layout slide you need and replace the placeholder text.
Keep the footer (group name, site URL, page number) on content slides.

## Email signatures

`trg-email-signatures.html` — a personalized signature block for each group
member. Open the file in a browser, copy your block, paste it into your mail
client's signature editor, and replace the placeholder with your UCLA email.

## Identity

`trg-mark.svg` — the full TRG mark in the hazard palette.
`favicon.svg` — the G-ligature medallion.
For UCLA-color versions of the logo, ask ET for the original artwork.
